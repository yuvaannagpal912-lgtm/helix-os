⬇ How to run Helix OS


Follow these simple steps:

Step 1 — Download Helix OS ISO

⬇ Download Helix OS v0.6 ISO

Step 2 — Download VirtualBox (free)

⬇ Download VirtualBox

Step 3 — Create a new Virtual Machine

Open VirtualBox → New → Name: Helix OS → Type: Other → Version: Other/Unknown


Step 4 — Load the ISO

Settings → Storage → Controller IDE → Add ISO → Select helix.iso


Step 5 — Boot Helix OS!

Click Start and enjoy Helix OS! 🎉

About Helix OS

Helix OS is a hobby operating system built from scratch by Yuvaan. It is written in C and x86 Assembly and runs on QEMU. The goal is to build a Windows-like OS from the ground up, learning every aspect of operating system development along the way.
